# Taylor Jones Portfolio

Live portfolio website for Taylor Jones, a Strategic Marketing & Communications Leader focused on brand storytelling, PR writing, editorial work, and content strategy.

## Live App

[View the live portfolio](https://taylorjones.vercel.app/)

## About

This site presents Taylor's professional background, featured writing samples, campaign and content strategy work, resume, writing portfolio, and contact links in a polished online portfolio format.

## Built With

- React
- Vite
- Custom CSS
- Vercel

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
